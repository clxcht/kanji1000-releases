# Kanji 1000

A Japanese study app: hiragana and katakana practice, the 1000 most common Jōyō kanji with
meanings, key words, stroke order and spaced-repetition flashcards, and graded reading practice.

## Download

1. Go to [**Releases**](https://github.com/clxcht/kanji1000-releases/releases/latest) and download `kanji1000.zip`.
2. Unzip it.
3. Open `kanji1000/index.html` in your browser.

No install or server needed. Your progress is saved in the browser you use. To move it to
another device, use **Mastery → Export progress**, then **Mastery → Import progress** there.
